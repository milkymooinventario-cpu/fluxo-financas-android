# Fluxo Finanças Android V3

Projeto Android contendo a versão mais recente do Fluxo Finanças.

## APK automático
O GitHub Actions gera um APK debug automaticamente a cada push em `main`.
Também é possível iniciar manualmente em Actions > Build APK > Run workflow.

Artefato esperado:
`Fluxo-Financas-APK`
